# 验收与测试 Spec

## 1. 功能验收

- [ ] 使用种子账号可登录；错误凭据返回统一提示；退出后受保护页面不可访问。
- [ ] 工作台展示数据库中的班级统计、今日课程、值日与待办。
- [ ] 花名册可搜索、新增和编辑学生；重复学号有明确提示。
- [ ] 花名册对原始性别为 `OTHER` 但姓名具有明确提示的学生显示“男/女 + 姓名推断”，不改写数据库原始性别。
- [ ] 通讯录可维护多名监护人并标记唯一主联系人。
- [ ] 座次表可保存布局，保留过道，拒绝重复学生、重复位置和越界位置。
- [ ] 座次表支持拖放/点击分配、交换、取消安排、撤销重做，以及左右侧窗户和门口标记的保存。
- [ ] 座次图顶部方向与配置控件在桌面端保持单行；前后边界固定显示，饮水机和空调可在左右前后四侧槽位中切换。
- [ ] 左右固定设施按排号、前后固定设施按列号与座位网格同步显示，调整行列后位置仍有效。
- [ ] 编辑座次时学生池默认显示为紧凑悬浮入口并重点显示未分配人数；展开后可搜索学生，未分配学生优先，拖拽和移动端视口边界均可用。
- [ ] 编辑态空座不显示下拉选择框；点击学生卡打开的操作菜单支持外部点击和 Escape 收起，座位姓名放大并居中。
- [ ] 值日表可维护工作日、区域、组名和成员。
- [ ] 班委名单可维护职务、职责与排序。
- [ ] 课程表按工作日和 8 节课展示并可保存。
- [ ] 成绩分析正确排除缺考，显示均分、最高/最低分、及格率和总分排名。
- [ ] 所有业务数据写入 MySQL，刷新页面后仍存在。

## 2. 自动化测试

### 单元测试

- 座次布局验证：重复学生、重复位置、越界、有效交换。
- 成绩统计：空集合、缺考、小数分、及格边界、总分排名并列。
- 认证令牌：令牌随机性、数据库仅存哈希、过期判断。
- Zod 输入 Schema：合法值与边界错误。

### 集成测试

- 登录 Route Handler：成功、错误密码、停用用户、Cookie 属性。
- 班级数据接口：未登录 401、跨班级 403、唯一冲突 409。
- 批量座次与成绩写入：事务成功以及失败不产生部分写入。

### E2E

1. 登录 → 工作台 → 退出。
2. 登录 → 花名册搜索 → 编辑学生 → 刷新后数据保留。
3. 登录 → 成绩分析 → 切换考试 → 查看统计与排名。

## 3. 质量门槛

- `npm run lint`、`npm run typecheck`、`npm test`、`npm run build` 全部通过。
- Vitest 全局行、语句、函数和分支覆盖率不低于 80%。
- 不提交 `.env`、数据库凭据、明文密码或真实学生/家长信息。
- 桌面端 Chrome 和 768px 平板宽度下无阻断性布局问题。

## 4. Definition of Done

代码、迁移、种子数据、Docker 开发环境、README、Spec 和自动化测试同时完成，才视为首版可交付。若本地未提供 Docker 或浏览器，允许将依赖外部环境的测试标记为“已实现、未在本机执行”，但单元测试、类型检查和构建不可省略。
