# 产品 Spec：高中班主任日常工作台

## 1. 背景与目标

高中班主任日常信息散落在表格、纸质座次表和多个通讯工具中。首版产品提供一个班级维度的统一工作台，让班主任在一个系统中查看当天安排、维护学生资料、组织班级事务并分析考试成绩。

首版成功标准：班主任能够在登录后 3 次点击内进入当前启用的工作区模块；名册、座次和通讯录可通过界面维护，并可在工作台查看当日课程、值日和考试概况。

当前工作区主导航只暴露工作台、座次表、花名册和家长通讯录。值日、班委、课程表与成绩相关页面保留在代码库中，但在其完整工作流重新启用前不作为工作区入口展示。

## 2. 用户与权限

### 2.1 系统管理员

- 创建/停用账号与班级。
- 将班主任加入班级。
- 访问其管理范围内的班级数据。

### 2.2 班主任

- 访问自己所属班级。
- 管理学生、监护人、座次、值日、班委、课程表、考试和成绩。
- 查看本班仪表盘与成绩分析。

### 2.3 权限边界

- 未登录用户只能访问登录页和健康检查。
- 用户只能访问其 `ClassMembership` 中的班级。
- 前端隐藏功能不构成授权；每个服务端接口必须再次校验会话与班级成员关系。

## 3. 首版范围

### 3.1 登录系统

- 用户名与密码登录、退出、会话恢复。
- 密码使用强哈希保存，连续失败给出通用错误，不暴露账号是否存在。
- 会话 7 天过期；Cookie 使用 `HttpOnly`、`SameSite=Lax`，生产环境启用 `Secure`。

### 3.2 工作台

- 展示学生总数、男女生人数、今日课程、今日值日、待办数量、最近考试。
- 展示快捷入口和近期班级事项。

### 3.3 座次表

- 按“面向讲台”的视角展示座位。
- 保留过道结构；支持设置行列并在缩小布局时提示受影响的学生。
- 支持从学生池拖入座位、拖动已安排学生交换座位、拖回学生池取消安排，也可通过点击和下拉完成调整。
- 支持在座位图左右两侧配置窗户和门口所在排位。
- 座位图以讲台所在的前方固定边界和教室后墙所在的后方固定边界作为方向参照；饮水机、空调可固定在左、右、前、后四侧。
- 左右侧固定设施按座位排定位，前后侧固定设施按座位列定位，并与座位网格同步。
- 编辑时学生池默认收起为紧凑悬浮入口，重点显示未分配人数；展开后可搜索学生，未分配学生优先展示并可继续拖放，不遮挡首屏座位布局。
- 支持撤销、重做、恢复上次保存版本，并在保存前显示未保存状态。
- 同一班级内学生和座位均不可重复。

### 3.4 值日表

- 按周一至周五展示值日小组、区域和成员。
- 支持新增、编辑、删除值日组和成员分配。

### 3.5 成绩分析

- 创建考试、科目和学生成绩。
- 展示总分排行、平均分、最高分、最低分、及格率和各科对比。
- 缺考成绩使用 `absent` 标识，不按 0 分参与均值与及格率。

### 3.6 花名册

- 查看、搜索、新增、编辑学生基本资料。
- 学号在班级内唯一；支持在读、休学、转出、毕业状态。

### 3.7 班委名单

- 维护班委职务、学生、职责与排序。
- 同一学生可承担多个职务；同一班级内职务名称唯一。

### 3.8 家长通讯录

- 每名学生可维护多个监护人。
- 展示关系、手机号、微信和工作单位；主联系人优先显示。
- 手机号仅对有班级访问权的用户返回。

### 3.9 课程表

- 周一至周五、每天 8 节课的网格视图。
- 维护课程、任课教师、教室和展示颜色。

## 4. 核心用户旅程

1. 作为班主任，我登录系统并看到本班今日概况，以便快速开始一天工作。
2. 作为班主任，我搜索学生并更新其资料和家长联系方式，以便保持信息准确。
3. 作为班主任，我拖选或通过表单调整座位，以便生成无冲突的座次表。
4. 作为班主任，我为工作日安排值日组，以便学生清楚当日职责。
5. 作为班主任，我录入一次考试成绩并查看科目统计和总分排行，以便识别需要关注的学生。
6. 作为班主任，我维护课程与班委信息，以便日常查询和班级公示。

## 5. 非功能要求

- 可用性：常用列表首屏加载目标小于 2 秒（100 名学生规模，正常局域网）。
- 可访问性：表单具有明确标签；核心操作可使用键盘；颜色不作为唯一状态表达。
- 响应式：`>= 1200px` 完整侧栏，`< 992px` 折叠菜单；表格允许横向滚动。
- 可维护性：UI、领域服务、数据仓储和 Route Handler 分层；不得从客户端直连数据库。
- 可观测性：服务端错误带 `requestId`，敏感字段和密码不得写入日志。

## 6. 明确非目标

- 首版不包含学生/家长自助登录、短信通知、请假审批、行为量化、文件导入导出、排课算法和多校 SaaS 计费。
- 首版不支持多人实时协作冲突合并；通过更新时间检测和数据库唯一约束避免静默覆盖。
